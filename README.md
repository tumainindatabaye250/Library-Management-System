
# Library Management System

A Fullstack Library Management System developed using React JS, Node JS, Express JS, and MySQL.  
The system helps manage books and borrowing operations in a library environment.

---

# Technologies Used

## Frontend
- React JS
- Vite
- Axios
- CSS

## Backend
- Node JS
- Express JS
- MySQL

---

# Features

- Add books
- View books
- Borrow books
- View borrowing records
- REST API integration
- MySQL database connection

# Installation

## Backend

```bash
cd backend
npm install
npm run dev
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

# Database Setup

Create database:

```sql
CREATE DATABASE library_db;
```

Import SQL file from:

```bash
database/library_db.sql
```

---

# Environment Variables

Create `.env` inside backend folder:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=library_db
PORT=5000
```
